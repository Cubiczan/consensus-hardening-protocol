# Moved

The canonical home of the Cubiczan **standard kit** is now
[`consensus-hardening-protocol`](https://github.com/icohangar-ops/consensus-hardening-protocol)
— this repository holds it, including the evidence-matrix gate
(`tools/verify_evidence_matrix.py`, vendored via `inject_stack.py --kit evidence`).

Historical pointer (2026-08): the `.chp` **kit injector** formerly driven from
[`_cubiczan-shared`](https://github.com/icohangar-ops/_cubiczan-shared) is `chp init`
here — install from [PyPI](https://pypi.org/project/consensus-hardening-protocol/)
(`pip install consensus-hardening-protocol`) or, for TypeScript Profile B, from
[npm](https://www.npmjs.com/package/@cubiczan/chp) (`npm install @cubiczan/chp`).
That repository is retained for history and is archived.
