# Moved

The `.chp` **kit injector** formerly driven from this repo is now `chp init` in [`consensus-hardening-protocol`](https://github.com/icohangar-ops/consensus-hardening-protocol). Install from [PyPI](https://pypi.org/project/consensus-hardening-protocol/) (`pip install consensus-hardening-protocol`) or, for TypeScript Profile B, from [npm](https://www.npmjs.com/package/@cubiczan/chp) (`npm install @cubiczan/chp`). This repository is retained for history and will be archived.
